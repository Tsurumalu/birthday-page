把 mp3 放进这个文件夹，文件名对应 js/music.js 里 TRACKS 配置的 file 字段：

  sunset-drive.mp3   ->  Sunset Drive
  neon-nights.mp3    ->  Neon Nights
  starry-coast.mp3   ->  Starry Coast
  for-you.mp3        ->  For You
  midnight-fm.mp3    ->  Midnight FM
  paper-moon.mp3     ->  Paper Moon
  gasoline-heart.mp3 ->  Gasoline Heart
  aqua-veil.mp3      ->  Aqua Veil
  honey-sky.mp3      ->  Honey Sky
  velvet-rain.mp3    ->  Velvet Rain

放好之后播放器会自动用真实音频，没有文件时页面以"静音试运行"模式模拟播放。
